# Macros

Приложение для Windows 10/11: записывает клавиатуру и мышь, хранит макросы и воспроизводит их с исходными паузами. Компактный интерфейс с иконками [Lucide](https://lucide.dev/).

## Запуск

Скачайте **Macros.exe** из [последнего релиза](https://github.com/AdlerDaniel/Macros/releases/latest) и поместите в папку, доступную для записи, например `Документы\Macros`. Python и другие программы не требуются. Запустите EXE.

- **F6** — начать/закончить запись. Перед записью окно сворачивается, ввод начинается через 0,45 секунды.
- **F8** — начать/остановить выбранный макрос.
- **F10** — остановить запись, воспроизведение или подготовку.

Горячие клавиши меняются в настройках. Если сочетание занято другой программой, приложение сообщит об этом. Обычные буквы требуют модификатор, например `Ctrl+Alt+R`.

Иконки клавиатуры и мыши выбирают устройства для записи. Нажатия, отпускания, движение, клики и вертикальная/горизонтальная прокрутка сохраняются вместе со временем. Клавиши завершения записи в макрос не включаются. При остановке воспроизведения зажатые макросом клавиши и кнопки отпускаются.

Кнопка прицела рядом с мышью или настройка **«Учитывать координаты мыши при записи»** выбирает режим новых записей:

- **Включено:** сохраняется начальная позиция курсора. При запуске и перед каждым повтором курсор возвращается туда, затем воспроизводит записанную траекторию в абсолютных координатах.
- **Выключено:** сохраняются смещения от начала записи, без координат экрана. Воспроизведение начинается от текущего положения курсора; следующий повтор продолжает движение от текущей точки.

Режим сохраняется внутри каждого макроса, включая экспорт и дублирование. Переключатель влияет на новые записи и кликеры. Ранее сохранённые макросы продолжают использовать абсолютные координаты.

Запись сохраняет каждую точку движения, сообщённую Windows, без удаления частых событий. При воспроизведении промежутки между точками заполняются с шагом в один пиксель и точным таймером; длительные паузы сохраняются. Физический путь между измерениями мыши восстанавливается прямыми отрезками. Потерянные в старой версии точки восстановить нельзя — такую траекторию лучше записать заново.

Запись автоматически сохраняется. Выбранный пустой макрос заполняется записью; если выбран уже заполненный, создаётся новый. Имя можно изменить в верхнем поле. Есть дублирование, удаление, импорт и экспорт JSON.

Число повторов задаётся в поле `×`, кнопка **∞** включает бесконечный цикл. Следующие поля задают скорость и паузу между повторами. Кнопка курсора в библиотеке создаёт кликер: укажите интервал и наведите курсор на точку в течение 3 секунд. Кликер нажимает левую кнопку мыши в этой точке.

## Данные и обновления

Макросы и настройки хранятся в `%LOCALAPPDATA%\Macros\library.json`, отдельно от EXE. Приложение ничего не записывает до явного начала записи и не отправляет макросы на сервер.

При запуске EXE автоматически проверяет GitHub Releases. Новая версия загружается по HTTPS, проверяется по размеру и SHA-256 из манифеста релиза и заменяет EXE с перезапуском. Во время записи и воспроизведения установка откладывается. При неуспешном старте новой версии восстанавливается предыдущий EXE. Макросы сохраняются. Автообновление можно выключить в настройках. Без интернета приложение продолжает работать.

EXE должен находиться в папке, доступной для записи. Для управления программой, запущенной от администратора, Macros также нужны соответствующие права. Некоторые игры блокируют искусственный ввод. Координаты мыши абсолютные; положение окон и расположение мониторов при воспроизведении должны соответствовать записи.

## Разработка и публикация

Python 3.11 x64 на Windows:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe tools\build.py
dist\Macros.exe --self-test artifacts
```

`tools/build.py` собирает автономный EXE, `update.json` и `SHA256SUMS.txt`. Самопроверка проверяет реальные hooks Windows, глобальные горячие клавиши, запись, воспроизведение, остановку и сохранение библиотеки в отдельной временной папке. Для неё нужен интерактивный рабочий стол без другого экземпляра Macros.

Для следующего обновления увеличьте `VERSION` в `app_config.py`, проверьте приложение, затем отправьте изменения в `main`. GitHub Actions выполняет тесты, собирает EXE и публикует релиз `vVERSION` с файлами обновления. Уже опубликованная версия не перезаписывается. Привязка GitHub сама по себе не отправляет незакоммиченные изменения: обновления публикуются через commit/push после проверок.

Все эти шаги можно выполнить одной командой: `.venv\Scripts\python.exe tools\release.py 1.0.2`. Она повышает версию, выполняет тесты и самопроверку собранного EXE, отправляет обновление на GitHub и публикует именно тот EXE, который прошёл проверку Windows. Затем проверяет файлы релиза. GitHub Actions дополнительно проверяет исходный код и делает контрольную сборку; опубликованную версию не заменяет.
